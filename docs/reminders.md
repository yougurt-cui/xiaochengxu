# 本地提醒

入口：宠物 → 我的提醒。页面为 reminders（列表 / 历史）、reminder-types（类型选择）、reminder-edit（新增 / 编辑）。沿用主题 token，主要按钮固底。

数据访问集中在 utils/reminders.js，使用 pet-store 的账号隔离存储，reminders 保存待办，reminderHistory 保存完成时的名称、宠物、备注和计划时间快照。完成重复提醒时，按原计划周期找到完成时间之后的下一次时间，跳过错过周期；月底按目标月最后一天处理，并保留原始日期锚点。删除提醒保留完成历史。

此版本仅在小程序内展示待办与逾期，不注册系统通知或订阅消息。清理本地存储或更换设备后不会同步。未来接入 API 时替换 repository 方法，并单独接入订阅消息授权及服务端调度。
